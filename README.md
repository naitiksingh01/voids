# Cohort Interviewer

AI-powered technical interview agent for graduates of a 31-day AI Engineering bootcamp.

Personalized interviews based on each candidate’s real learning history (missions passed/skipped, attempts, role, engagement signals).

## Features

- Exact data model from the brief
- Real personalization engine (strengths / struggles / gaps / role weighting)
- Transparent “Interviewer’s prep notes” panel
- Stateful multi-turn interview (≥8 questions, ≥4 curriculum days)
- Follow-up questions + graceful “I don’t know” handling
- Clean Linear/Vercel-style dark UI
- Structured feedback report
